# Gayatri Birthday Website 🎂

A small, cute birthday landing page made with plain HTML, CSS and JavaScript.

## GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/root`.
4. Save and open the generated GitHub Pages URL.

No build step is required.

## Personalize
The main message is inside `index.html`. You can change the note in the `.caption` section if you want it more personal.
